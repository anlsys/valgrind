# Notes discussions JB / Romain 31/07 matin

- Valgrind vs DynamoRIO vs Thread Sanatizer LLVM
    - Valgrind vs DynamoRIO : single-threaded vs multi-threaded; pas un problème; Valgrind possiblement plus robuste
    - Thread Sanatizer LLVM : programme compilé, parallèle, possiblement bien plus rapide que Valgrind. Avec Valgrind, on peut théoriquement skip l'exécution de basics blocs pas intéressant (probablement difficile en pratique)


1/ Objectif - associer les accès mémoires à chaque tâche:
TASK ID ; OP   ; ADDR    ; SIZE
task 1    ; STORE ; 0x70640 ; 4
task 1.1  ; LOAD  ; 0x70640 ; 4
task 1.2  ; LOAD  ; 0x70640 ; 4
task 2    ; STORE ; 0x70644 ; 4
[...]

Besoin d'un identifiant de tâche unique, consistant entre 2 exécutions.

Exemple:

```C
// 1
# pragma omp task
{
    // 1.1
    # pragma omp task
    {
    }

    // 1.2
    # pragma omp task
    {
    }
}

// 2
# pragma omp task
{
}

```
